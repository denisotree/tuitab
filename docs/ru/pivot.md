# Сводные таблицы

> 🇬🇧 [This page in English](../en/pivot.md) · [← Оглавление документации](README.md)

Сводная таблица перекрёстно группирует данные: один набор столбцов становится
**строками**, значения другого столбца — **столбцами**, а агрегация заполняет
ячейки.

![Сводная таблица](https://raw.githubusercontent.com/denisotree/tuitab/master/.github/assets/pivot.gif)

## Как это работает

В отличие от мастера в электронных таблицах, tuitab берёт раскладку сводной из
состояния таблицы:

1. **Строки (индекс)** — столбцы, которые вы **закрепили** через `!`.
2. **Столбцы (разворот)** — столбец под **курсором**.
3. **Ячейки** — **формула агрегации**, которую вы вводите после нажатия `W`.

Поэтому окно `W` спрашивает только формулу, например `sum(revenue)`.

## Формула агрегации

Используйте эти агрегирующие функции по столбцу:

| Функция | Результат |
|---------|-----------|
| `sum(col)` | Сумма |
| `count(col)` | Количество значений |
| `mean(col)` | Среднее |
| `median(col)` | Медиана |
| `min(col)` / `max(col)` | Минимум / максимум |

Формулы можно комбинировать с арифметикой:

```text
sum(revenue)
count(order_id)
sum(revenue) / sum(units)      # средняя цена за единицу
```

Поле помнит историю (`↑` / `↓`) и дополняет имена столбцов (`Tab`).

## По шагам

```sh
tuitab sales.csv     # столбцы: date, region, category, units, revenue
```

1. Встаньте на `region` и закрепите его через `!` — это станет индексом строк.
2. Переведите курсор на `category` — его значения станут столбцами.
3. Нажмите `W`, введите `sum(revenue)`, нажмите `Enter`.

Результат — сетка **region × category** с суммой выручки в каждой ячейке,
открытая как новый лист. Нажмите `Esc` / `q`, чтобы вернуться.

> Закрепите **несколько** столбцов, чтобы вложить индекс строк (например,
> закрепите `region` *и* `category`, затем сведите другой столбец).

## Обратно: unpivot

Широкая таблица — колонка на страну, на эндпоинт — становится длинной через `gW`:
закрепите столбцы, которые определяют строку (`Time`), нажмите `gW`, и каждый
остальной столбец станет строками (`variable`, `value`) на новом листе, с
закреплёнными столбцами на каждой. В MCP это операция `unpivot`.
