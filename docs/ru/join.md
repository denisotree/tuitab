# JOIN

> 🇬🇧 [This page in English](../en/join.md) · [← Оглавление документации](README.md)

Нажмите `J`, чтобы соединить текущую таблицу с другой через пошаговый мастер.
Вторая таблица может быть **любым файлом, который открывает tuitab** (CSV, TSV,
JSON, JSONL, YAML, TOML, Parquet, Arrow, Excel, Markdown, SQLite, DuckDB) либо
другим уже открытым листом.

![Мастер JOIN](https://raw.githubusercontent.com/denisotree/tuitab/master/.github/assets/join.gif)

## Четыре шага

### 1. Выберите правую таблицу

В окне перечислены:

- **`[Browse file…]`** — введите путь (`Tab` дополняет) к любому поддерживаемому
  файлу.
- **Открытые листы** — другие листы, уже находящиеся в стеке.

### 2. Выберите тип соединения

| Вариант | Аналог в SQL | Какие строки остаются |
|---------|--------------|-----------------------|
| `INNER` | `INNER JOIN` | Только строки с совпадением в обеих таблицах |
| `LEFT` | `LEFT JOIN` | Все строки левой; несопоставленные ячейки правой — null |
| `RIGHT` | `RIGHT JOIN` | Все строки правой; несопоставленные ячейки левой — null |
| `OUTER` | `FULL OUTER JOIN` | Все строки обеих таблиц |
| `ANTI` | `WHERE NOT EXISTS (…)` | Строки левой, у которых нет пары в правой |
| `SEMI` | `WHERE EXISTS (…)` | Строки левой, у которых есть пара в правой |
| `DIFF` | — | Построчное сравнение двух таблиц, как `git diff` — см. ниже |

ANTI и SEMI оставляют только столбцы левой таблицы, и NULL в ключе совпадает с
NULL (в DIFF тоже) — две пустые ячейки считаются одинаковыми. Остальные четыре следуют SQL,
где NULL ни с чем не совпадает.

### 3. Выберите ключевые столбцы слева

Список столбцов текущей таблицы с галочками. Переключайте `Space` или нажмите `a`,
чтобы взять все столбцы (повторно — снять). **Порядок** выбора важен — левый
ключ 1 сопоставляется с правым ключом 1 и так далее. Рядом со столбцом показан
его тип. Нажмите `Enter`, чтобы продолжить.

### 4. Выберите ключевые столбцы справа

Тот же список для второй таблицы. Столбцы с такими же именами, как у левых
ключей, отмечены заранее. Поправьте и нажмите `Enter`, чтобы выполнить
соединение.

> Количество ключей должно совпадать: два левых ⇒ ровно два правых. При
> несовпадении в строке состояния появится ошибка.

> Парные ключи должны быть одного типа. Правый ключ, тип которого несовместим с
> левой парой, подсвечен красным, а `Enter` вместо соединения называет оба
> столбца и их типы. Смените тип одного из них клавишей `t` и запустите JOIN
> снова; чтобы сменить тип столбца в файле, сначала откройте его как лист. Целые
> разной разрядности, дробные разной разрядности и datetime разной точности
> сопоставляются как есть.

## Результат

В стек добавляется новый лист с заголовком `left JOIN right` (`left ANTI JOIN
right`, `left SEMI JOIN right`, `left DIFF right`). Нажмите `Esc` / `q`,
чтобы вернуться к исходной таблице. Неключевые столбцы, существующие в обеих
таблицах, получают суффикс `_right`, чтобы ничего не перезаписалось.

## Разбор примера

```sh
# orders.csv:    order_id, customer_id, amount
# customers.csv: customer_id, name, country
tuitab orders.csv
```

1. Нажмите `J`.
2. Выберите **`[Browse file…]`**, введите `customers.csv`, нажмите `Enter`.
3. Выберите **LEFT**, нажмите `Enter`.
4. Отметьте `customer_id` слева, нажмите `Enter`.
5. Отметьте `customer_id` справа, нажмите `Enter`.

Результат — каждый заказ, дополненный `name` и `country` своего клиента.

## Как найти расхождения между двумя таблицами

DIFF сравнивает две таблицы так же, как `git diff` сравнивает два файла. Ключи
определяют, какие строки — одна и та же строка; все остальные общие столбцы
сравниваются.

```sh
tuitab march.csv
```

1. Нажмите `J`, выберите **`[Browse file…]`**, введите `april.csv`, нажмите `Enter`.
2. Выберите **DIFF**, нажмите `Enter`.
3. Отметьте столбец, который идентифицирует строку (например `id`), нажмите `Enter`.
4. Правый ключ уже сопоставлен по имени — нажмите `Enter`.

```
 _diff │ id name   city   amount  name_right city_right amount_right
 =     │ 1  Anna   Lisbon 100
 =     │ 2  Boris         200
 ~     │ 3  Clara  Porto  300                           350
 -     │ 4  Dmitry Faro   400
 +     │ 5  Elena  Braga  500
```

- `_diff` закреплён первым: `=` без изменений, `~` изменена (жёлтая, отличающиеся
  ячейки выделены), `-` есть только в левой таблице (красная), `+` только в правой
  (зелёная).
- `<столбец>_right` показывает значение правой таблицы только там, где оно
  отличается от левого.
- Строки левой таблицы идут в своём порядке, добавленные — в конце. В строке
  состояния — счётчики каждого вида.
- NULL равен NULL и в ключах, и в ячейках; значение, ставшее NULL, — это изменение.
- `_diff` — обычный столбец: отфильтруйте по нему, чтобы оставить только
  изменения, или нажмите на нём `F`, чтобы увидеть счётчики.

Нажмите `a` на шаге 3, чтобы взять ключами все столбцы: тогда изменённая строка
показывается парой `-` и `+`, как в git, и строк `~` не будет.

Ключ должен быть уникальным с обеих сторон — если на ключ приходится две строки,
непонятно, какую с какой сравнивать, и DIFF попросит добавить столбцы в ключ.
Столбцы, которые есть только в одной таблице, попадают в результат, но не
сравниваются.
