# Горячие клавиши

> 🇬🇧 [This page in English](../en/keybindings.md) · [← Оглавление документации](README.md)

Полный справочник команд. Нажмите `?` в tuitab для встроенной шпаргалки.
Все клавиши ниже — для **обычного режима** (Normal), если не указано иное. Многие
команды действуют на **столбец под курсором** или на **выделенные строки**.

## Навигация

| Клавиша | Действие |
|---------|----------|
| `h` `j` `k` `l` / стрелки | Переместить курсор влево / вниз / вверх / вправо |
| `gg` | Перейти к первой строке |
| `G` / `End` | Перейти к последней строке |
| `Home` | Перейти к первой строке |
| `Ctrl+F` / `PageDown` | Страница вниз |
| `Ctrl+B` / `PageUp` | Страница вверх |
| `q` / `Esc` | Выход — или возврат на один лист назад, если вы углубились |

## Сортировка

| Клавиша | Действие |
|---------|----------|
| `[` | Сортировать по возрастанию по столбцу под курсором |
| `]` | Сортировать по убыванию по столбцу под курсором |
| `gb` | Группировка по закреплённым столбцам с агрегатами, отмеченными через `+` |
| `zw` | Добавить оконный столбец: ранг, накопительный итог, соседняя строка, доля в группе. Накопительный итог спросит, по какой колонке упорядочить строки — саму таблицу это не пересортирует — затем направление и партиции |
| `z[` | Добавить столбец под курсором как ещё один ключ сортировки, по возрастанию |
| `z]` | Добавить столбец под курсором как ещё один ключ сортировки, по убыванию |
| `r` | Вернуть исходный порядок строк |

## Поиск и выбор строк

| Клавиша | Действие |
|---------|----------|
| `/` | Поиск — подсвечивает ячейки по регулярному выражению |
| `n` / `N` | К следующему / предыдущему совпадению |
| `c` | Снять подсветку поиска |
| `,` | Выбрать строки, где ячейка равна текущему значению |
| `\|` | Выбрать строки по регулярному выражению или по выражению с префиксом `!=` (например, `\|!=age > 30`) |
| `s` / `u` | Выбрать / снять выбор текущей строки |
| `gs` / `gu` | Выбрать все / снять выбор со всех строк |
| `gt` | Инвертировать текущее выделение |
| `Shift+S` `r` | Выбрать **N** случайных строк |
| `Shift+S` `d` | Выбрать все строки, у которых есть дубликаты |
| `Shift+S` `D` | Умная дедупликация — оставляет по одной строке на группу (спросит критерий, если есть закреплённые столбцы) |
| `d` | Удалить выделенные строки |
| `"` | Создать новый лист из выделенных строк |

Язык фильтра `|!=` описан в [Выражениях](expressions.md).

## Столбцы

| Клавиша | Действие |
|---------|----------|
| `!` (`Shift+1`) | Закрепить / открепить столбец (остаётся виден при прокрутке; используется графиками и сводными) |
| `_` | Перебрать ширину столбца |
| `g_` | Перебрать ширину всех столбцов |
| `=` | Добавить вычисляемый столбец из [выражения](expressions.md) |
| `t` | Открыть меню **типа** столбца (строка, целое, дробное, дата, дата-время, логический, проценты, валюта, размер файла) — при выборе **Currency** можно указать USD / EUR / GBP / JPY |
| `+` | Добавить агрегатор-итог по столбцу (множественный выбор по `Space`) |
| `-` | Очистить агрегаторы столбца |
| `Z` | Быстрая агрегация видимых / выделенных значений в строку состояния |

### Операции со столбцами (префикс `z`)

| Клавиша | Действие |
|---------|----------|
| `ze` | Переименовать столбец |
| `zd` | Удалить столбец |
| `zi` | Вставить пустой столбец |
| `zs` / `zu` | Отметить / снять отметку столбца (отмеченные показаны с `*` и учитываются при копировании) |
| `z←` / `zh` | Сдвинуть столбец влево |
| `z→` / `zl` | Сдвинуть столбец вправо |
| `z.` / `z>` | Увеличить число знаков после запятой |
| `z,` / `z<` | Уменьшить число знаков после запятой |
| `zf` | Добавить столбец «% от итога» |
| `zF` | Добавить столбцы «% от итога» по разбиению (выберите столбцы разбиения) |
| `zr` | Найти и заменить текст в столбце |
| `zg` | Найти и заменить по регулярному выражению |
| `zx` | Разбить столбец по разделителю |
| `zo` | На листе каталога: открыть выбранный файл как указанный формат |
| `zEnter` | Провалиться в узел из текущей ячейки (JSON/YAML/TOML) |

## Строки, листы и аналитика

| Клавиша | Действие |
|---------|----------|
| `Enter` | Транспонировать текущую строку в вид Столбец/Значение (детализация); на листе JSON/YAML/TOML — провалиться в узел строки |
| `T` | Транспонировать всю таблицу (повторное нажатие отменяет) |
| `I` | Сводка по листу — статистика по столбцам |
| `F` | Таблица частот для столбца под курсором |
| `gF` | Таблица частот по нескольким столбцам (группирует по закреплённым) |
| `gD` / `gd` / `gU` | Дедупликация по закреплённым столбцам (оставляет первую строку в группе) |
| `V` | [График](charts.md) столбца под курсором |
| `W` | [Сводная таблица](pivot.md) |
| `J` | [JOIN](join.md) с другой таблицей |
| `e` | Редактировать текущую ячейку |
| `E` | Редактировать текущую ячейку в `$EDITOR`; на листе JSON/YAML/TOML ячейка-контейнер открывается как настоящее поддерево — можно добавлять, удалять и переставлять ключи |
| `m` | Переключить проекцию текущего узла: записи / ключ-значение / скаляры |
| `(` / `)` | Развернуть вложенный столбец в столбцы по ключам / свернуть обратно |
| `ge` | Массовое редактирование — задать одно значение всем выделенным строкам |
| `o` | Добавить пустую строку под курсором |
| `O` | Форма новой строки — по полю на столбец, каждое проверяется по типу столбца |

Форма (`O`) строится из столбцов листа: `↑` `↓` либо `Tab` / `Shift+Tab` переходят
между полями, `←` `→` двигают курсор внутри поля, `Enter` вставляет строку в конец
таблицы, `Esc` отменяет. Значение, которое столбец не может хранить, подсвечивается
прямо при наборе, и `Enter` не сработает, пока оно не исправлено — целочисленный
столбец не превратится молча в текстовый. Пустое поле означает NULL, а не пустую
строку; если хоть одно поле осталось пустым, первый `Enter` скажет сколько их и
подождёт, а вставит только второй. На листе базы данных `\N` тоже означает NULL —
так же, как при правке ячейки. На листе JSON/YAML/TOML форма недоступна.

## Буфер обмена (префикс `y`)

| Клавиша | Действие |
|---------|----------|
| `yc` | Скопировать текущую ячейку |
| `yr` | Скопировать выделенные строки (или текущую) — выбрать формат |
| `yz` | Скопировать столбец под курсором для выделенных строк — выбрать формат |
| `yZ` | Скопировать весь столбец под курсором — выбрать формат |
| `yR` | Скопировать всю таблицу — выбрать формат |
| `p` | Вставить буфер обмена в ячейку под курсором |
| `P` | Вставить строки из буфера обмена |

Копии строк/таблицы предлагают **TSV · CSV · JSON · Markdown**; копии столбца —
разделение переводом строки, запятой или запятой с кавычками. `yr` и `yR`
учитывают столбцы, отмеченные через `zs`.

## Файл

| Клавиша | Действие |
|---------|----------|
| `Ctrl+S` | Сохранить / экспортировать / конвертировать (CSV, TSV, Parquet, Arrow/Feather, JSON, JSONL, YAML, TOML, Excel, SQLite или DuckDB) |
| `R` | Перечитать файл с диска |
| `U` / `Shift+U` | Отменить (до 50 шагов) |
| `Ctrl+R` | Повторить |
| `?` | Показать / скрыть справку |

При сохранении обычной таблицы (CSV, Parquet, SQL, сводной) в JSON/YAML/TOML спросит,
какую форму сделать — `[{col: val}, …]`, `{col: [val, …]}` или `{a: b}` для таблицы из
двух столбцов — и запомнит ответ до конца сессии. Лист, за которым уже стоит документ,
не спрашивают: его дерево пересериализуется как есть. Сохранение в базу данных
сначала показывает каждый стейтмент — см. [Базы данных](database.md).

## Режим графика

| Клавиша | Действие |
|---------|----------|
| `h` `k` / `←` `↑` | Предыдущий столбик / точка |
| `l` `j` / `→` `↓` | Следующий столбик / точка |
| `Enter` | Детализация по выбранному столбику |
| `V` / `q` / `Esc` | Закрыть график |

## Режимы ввода

Когда вы вводите текст в поле (поиск, выражение, формула сводной,
переименование, путь сохранения, …):

| Клавиша | Действие |
|---------|----------|
| `←` `→` `Home` `End` | Перемещение текстового курсора |
| `Backspace` / `Delete` | Удалить слева / справа |
| `Tab` | Автодополнение (имена столбцов / пути к файлам, где доступно) |
| `↑` / `↓` | Предыдущая / следующая запись истории (поля выражения и сводной) |
| `Enter` | Применить |
| `Esc` | Отменить |

## Листы JSON / YAML / TOML

Эти форматы открываются как таблица поверх настоящего документа, а не как его
плоская копия. Формат берётся из расширения, из `--type` или — если расширение
незнакомое — из содержимого: `deploy.conf` с TOML внутри откроется как TOML. Файл
вообще без расширения по-прежнему читается как CSV и перечитывается как JSON только
если начинается с `[` или `{`.

| Клавиша | Действие |
|---------|----------|
| `Enter` | Провалиться в узел текущей строки |
| `zEnter` | Провалиться в узел текущей ячейки |
| `yp` | Скопировать путь текущей ячейки в документе (`servers[1].host`) |
| `q` / `Esc` | Подняться на уровень выше |
| `g/` | Поиск по всему документу — см. ниже |
| `gp` | Перейти к узлу по его пути в документе |
| `gq` | Выполнить jq-запрос и открыть результат листом |
| `m` | Переключить проекцию: записи / ключ-значение / скаляры |
| `(` | Развернуть столбец-контейнер в столбцы `родитель.ключ` / `родитель[0]` |
| `)` | Свернуть ближайшую развёртку обратно в один столбец |
| `e` | Правка скаляра — тип сохраняется, строка остаётся строкой |
| `E` | Правка контейнера как текста в `$EDITOR` (добавить, удалить, переставить ключи) |
| `d` | Удалить выделенные строки — удаляются из документа |
| `Ctrl+S` | Сохранить; другое расширение конвертирует формат |

`gq` выполняет jq-программу над документом — `.[] | select(.ok)`,
`.users | to_entries | map({name: .key, age: .value.age})` — и открывает результат
обычным листом: погружение, правка и сохранение на нём работают, потому что результат
это просто ещё один документ. Формат наследуется от исходника, так что сохранение
пишет файл того же вида, а вот путь — нет: `Ctrl+S` на результате запроса не предложит
перезаписать то, над чем запрос выполнялся.

`/` ищет по тому, что на экране, а на листе документа это одно поддерево, отрендеренное
в ячейки — ключ тремя уровнями ниже он не увидит. `g/` ищет по самому дереву и открывает
лист совпадений: строка на каждое, с путём, значением и пометкой, совпал ключ или
значение. Пути абсолютные от корня документа, поэтому `g/` означает одно и то же,
запущен он наверху или тремя уровнями ниже. `Enter` на совпадении открывает узел — контейнер как есть, для скаляра его
родителя, чтобы значение было видно в контексте, — и ставит курсор на совпадение. Само
ничего не открывается. Шаблон — регулярное выражение без учёта регистра, список
обрывается на 2000 совпадениях, о чём говорит статусная строка. Список — снимок: если
документ изменился после поиска, открытие совпадения отклоняется, а не рискует путём,
который теперь указывает в другое место — нужно повторить `g/`.

Когда сообщать нечего, статусная строка показывает путь ячейки под курсором —
`servers[1].host`. Это то, чем на значение можно сослаться где угодно ещё; `yp`
копирует путь, `gp` переходит по нему (поле заполнено текущим местом). Синтаксис у
всех трёх один, поэтому скопированный путь можно вставить обратно. Ключ, неоднозначный
в точечной записи, пишется как `["awkward.key"]`. Путь, который не разрешился, скажет,
докуда дошёл — `servers[1] exists`, — а не только что не вышло.

Конверсия, которая не всё унесёт, говорит об этом в статусной строке при сохранении —
multi-doc YAML в JSON или TOML с комментариями во что угодно ещё.

В режиме записей колонка — это ключ, поэтому `zd`, `ze`, `zi` и `z←`/`z→` меняют его
во всех записях, где он есть: удаляют, переименовывают на месте, добавляют со
значением null перед колонкой под курсором или меняют местами с соседним.
Переименование, которое столкнулось бы с существующим ключом хоть в одной записи,
ничего не меняет. У режимов ключ-значение и списка колонки фиксированные.

Операции, которые перестроили бы таблицу без соответствующего изменения в документе —
вставка, вычисляемые колонки, поиск с заменой и разбиение — отклоняются с подсказкой
про `E`.

Все листы одной цепочки погружения работают с одним документом, поэтому правка на
третьем уровне видна при возврате наверх, а `U` откатывает её на любом уровне.

Развёртка — операция только над видом: `(` не меняет документ, поэтому при сохранении
пишется настоящая вложенность, а не плоские имена `родитель.ключ`. Развёрнутые ячейки
остаются редактируемыми и пишут в тот узел, который реально адресуют.

Сохранение пересериализует документ целиком: вложенность, порядок ключей и даты TOML
сохраняются.

Файл TOML, сохранённый обратно в TOML, сохраняет комментарии и вёрстку: он пишется
через собственный исходник, а не собирается заново, поэтому правка одного значения в
конфиге оставляет остальной файл нетронутым. Теряются две вещи: комментарий на ключе,
который вы *переименовали* (для файла переименование — это удаление плюс вставка), и
комментарии внутри массива или таблицы, длина которых изменилась. При конвертации в
другой формат комментарии исчезают — в YAML и JSON их некуда деть.

## Раскладки клавиатуры

Раскладки, отличные от QWERTY — **ЙЦУКЕН** (русская), **QWERTZ** (немецкая) и
**AZERTY** (французская) — прозрачно переназначаются на позиции QWERTY, поэтому
горячие клавиши работают без переключения раскладки.
